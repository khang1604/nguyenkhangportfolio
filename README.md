# NguyenKhangPortfolio

A personal web portfolio showcasing background, achievements, key technical milestones, and projects.

## Tech Stack
- **Framework:** React 19 with Vite & TypeScript
- **Iconography:** FontAwesome SVG Core (`@fortawesome/react-fontawesome`)
- **Runtime Validation:** Zod
- **Architecture:** Feature-Driven Domain Architecture, Zero Root Clutter
- **Package Manager:** `npm`

## Getting Started

1. Navigate to frontend directory:
   ```bash
   cd frontend
   ```
2. Install dependencies (fixed package manager: `npm`):
   ```bash
   npm install
   ```
3. Run local development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```

## Directory Structure
- `frontend/`: React application source code, components, features, and styles.
- `docs/`: Architecture blueprints (`docs/architecture/`) and session progress logs (`docs/PROGRESS.md`).
- `.local/`: Centralized local development notes and scratchpad (gitignored).
- `AGENTS.md`: Repository guidelines, coding standards, and architectural rules.
